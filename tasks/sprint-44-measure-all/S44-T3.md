# Goal

Today `measure:links` reports `missed` (confirmed) and treats every other unlinked work as fine. That is wrong. Most of them were never settled: the check only proves a miss, it never proves there is no translation.

Give every unlinked work it checks exactly one class, and write the rule in `docs/contract.md` after **Measure all cached (S44).**, under the exact bold name **Unconfirmed unlinked works (S44).**

1. `missed`: the existing check found it. Keep it as it is.
2. Otherwise, ask Wikidata for the work's entity:
   - search the English title with `wbsearchentities`, then `wbgetentities` with `labels|descriptions|claims`;
   - accept an entity only if its English description or its P50 author's English label agrees with the work's author, using `sameAuthor` from `supabase/functions/_shared/author-sound.ts` or a surname match.

   Use the Wikimedia throttle the script already has: one request at a time, at least 300 ms apart, retry on 429.
3. If that entity has a Hebrew label:
   - search Simania for the label, with both ' and ׳;
   - if a result's author agrees with the work's author (the same author check the rematch uses), the class is `missed` with `via: "wikidata_he"`;
   - otherwise the class is `hebrew_label_unconfirmed`. A Hebrew label strongly suggests a translation, but there is no Simania edition.
4. If there is no entity, or no Hebrew label, the class is `no_evidence`.
5. If a call fails, the class is `failed`.

The printed JSON gets these counts:
- `missed`, `hebrew_label_unconfirmed`, `no_evidence` and `failed`;
- `missed_rate_low = missed / population`;
- `missed_rate_high = (missed + hebrew_label_unconfirmed + failed) / population`;
- `hebrew_label_titles`.

Population is in-use works by default, and all works with `--all`. With `--sample`, every count is scaled the same way as `missed_estimate`.

Tested on 2026-11-22 with Wikidata Hebrew labels:
- *Cloud Atlas* → ענן אטלס, *Hamnet* → המנט, *The Strange Case of Dr Jekyll and Mr Hyde* → המקרה המוזר של ד"ר ג'קיל ומר הייד;
- *Legends & Lattes* and *Bossypants* have no Hebrew label.

# Acceptance criteria

1. Tests with fakes cover:
   - every class;
   - a Hebrew label whose Simania results are by another author → `hebrew_label_unconfirmed`;
   - an entity whose author disagrees → not accepted.
2. The existing measure-links tests still pass, with the new fields added.
3. All verification commands pass.
