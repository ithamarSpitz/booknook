# Goal

The first-run prompt for an empty library, and an installable web app manifest.

# Scope

1. `first-run.js`: `shouldShow(shelves)` true when the user has no books at all; `mount` shows one short Hebrew line inviting them to add a book they loved, pointing at the "+" tile of "קראתי". It disappears once a book exists.
2. `manifest.webmanifest`: name Torimitor, `lang: "he"`, `dir: "rtl"`, `display: "standalone"`, theme and background colors from the pine palette in `css/base.css`, start URL `./#library`.
3. `public/icons/`: 192 and 512 PNG icons plus an Apple touch icon, generated by a small script you run once (do not commit the script outside your paths) or drawn as SVG and rasterized. Simple book or shelf mark in the pine palette.
4. Tests for `shouldShow`.

# Out of scope

Service worker and offline mode. `index.html` (the shell already links the manifest; if an Apple touch icon link is missing, report it instead of editing).

# Acceptance criteria

1. Manifest is valid JSON, icons exist.
2. Tests pass.
