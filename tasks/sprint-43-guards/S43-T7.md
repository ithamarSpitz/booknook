# Goal

Add `--hebrew` to `scripts/measure-links.ts`. It is the Hebrew side of **Link measurement (S43)**: Hebrew translations that are not linked to their original work.

Our working code is the example at the end of this brief. Port its check, keep its Wikimedia throttle, and stay read-only with no Hardcover calls:

1. Take every cached Hebrew edition with `simania_id > 0` and `work_id` null.
2. For each one, get `nliOriginal(title, author)`, then the Wikidata original, then the Simania translator (`bookDetails`).
3. Give it a kind:
   - `translation_with_original` when an original title in Latin script was found;
   - else `translated_no_original` when Simania names a translator;
   - else `provider_failure` when a call failed;
   - else `no_evidence`.

Add `"hebrew":{"unlinked_editions":136,"translation_with_original":50,"translated_no_original":30,"no_evidence":50,"provider_failure":6,"linked_editions":1200}` to the printed JSON. `linked_editions` counts editions with `simania_id > 0` and a `work_id`.

Put the per-edition decision in an exported function with injectable providers.

# Acceptance criteria

1. Tests with fakes cover all four kinds.
2. Both verification commands pass.

# Example (our working check, 2026-11-21)

```ts
import { openProdDb } from "file:///C:/Users/itas1/torimitor/scripts/lib/prod-db.ts";
// Throttle Wikimedia: one request at a time, >=300ms apart; on 429 wait (retry-after or 15s) and retry up to 6 times.
const realFetch = globalThis.fetch; let wmChain: Promise<unknown> = Promise.resolve(); let wm429 = 0;
globalThis.fetch = ((input: any, init?: any) => {
  const url = String(input?.url ?? input);
  if (!/wikidata.org|wiktionary.org|wikipedia.org/.test(url)) return realFetch(input, init);
  const run = async () => {
    for (let a = 0; ; a++) {
      await new Promise((r) => setTimeout(r, 300));
      const res = await realFetch(input, init);
      if (res.status !== 429 || a >= 6) return res;
      wm429++; const ra = Number(res.headers.get("retry-after")); await res.body?.cancel();
      await new Promise((r) => setTimeout(r, (ra > 0 ? ra : 15) * 1000));
    }
  };
  const p = wmChain.then(run, run); wmChain = p.catch(() => {}); return p;
}) as typeof fetch;
import { bookDetails } from "file:///C:/Users/itas1/torimitor/supabase/functions/_shared/simania.ts";
import { nliOriginal, wikidataOriginal } from "file:///C:/Users/itas1/torimitor/supabase/functions/_shared/bridges.ts";
const sql = await openProdDb({ readOnly: true });
const eds = await sql`select simania_id, title, author, resolve_status, exists (select 1 from public.shelf_books sb where sb.simania_id = e.simania_id) as shelf from public.editions e where simania_id > 0 and work_id is null order by simania_id`;
await sql.end();
for (const e of eds) {
  const d: any = await bookDetails(Number(e.simania_id)).catch(() => null);
  let n: any = null, w: any = null, err = false;
  try { n = await nliOriginal(String(e.title), String(e.author ?? "")); } catch { err = true; }
  try { w = await wikidataOriginal(String(e.title)); } catch { err = true; }
  const orig = n?.title ?? w?.title ?? null;
  const latin = orig && /[A-Za-z]/.test(orig) && !/[\u0590-\u05FF]/.test(orig);
  const translator = String(d?.translator ?? "").trim();
  const kind = latin ? "translation_with_original" : translator ? "translated_no_original" : err ? "provider_failure" : "no_evidence";
  console.log(JSON.stringify({ id: e.simania_id, t: e.title, a: e.author, shelf: e.shelf, status: e.resolve_status, kind, orig, src: n?.title ? "nli" : w?.title ? "wikidata" : null, translator: translator || null, lang: d?.originalLanguage ?? d?.language ?? null }));
}
```
